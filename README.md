# پویا

داشبورد مدیریت مالی شخصی، کاملاً فارسی و راست‌چین. پردازش داده، تبدیل ارز و ذخیره‌سازی تراکنش‌ها همگی در مرورگر انجام می‌شوند.

## اجرا

```bash
npm install
npm run dev
```

سپس آدرس `http://localhost:3000` را باز کنید.

برای کنترل نسخه تولید:

```bash
npm run typecheck
npm run build
npm start
```

## امکانات اصلی

- ورود متن یا فایل JSON با گزارش رکوردهای معتبر و نامعتبر
- پشتیبانی و نرمال‌سازی ریال و تومان با واحد پایه ریال
- تقویم، بازه زمانی، گزارش و مقایسه ماهانه جلالی
- نمودار جریان نقدی، درآمد و هزینه و دسته‌بندی‌ها
- جدول تراکنش‌ها با جستجو، فیلتر، مرتب‌سازی، صفحه‌بندی و جزئیات
- نمایش درختی حساب‌ها با مجموع، میانگین، تعداد و سهم
- گزارش‌های تحلیلی بدون هوش مصنوعی و مبتنی بر داده واقعی
- حالت روشن و تیره و چیدمان واکنش‌گرا
- ذخیره محلی و امکان دریافت نسخه پشتیبان

## حریم خصوصی

این نسخه Backend ندارد. داده‌های مالی فقط در `localStorage` مرورگر نگهداری می‌شوند و به سرور ارسال نمی‌شوند.

## آخرین بهبودها

- رفع خطای زمان اجرا در صفحه «ورود اطلاعات»: استفاده از `Dialog.Title` و `Dialog.Description` بیرون از `Dialog.Root` باعث خطای `DialogTitle must be used within Dialog` و از کار افتادن صفحه می‌شد.
- افزودن `app/icon.svg` برای حذف خطای ۴۰۴ آیکون در کنسول مرورگر.
- اعمال تم پیش از رندر اول (`next/script` با `beforeInteractive`) تا حالت تیره بدون پرش رنگ بارگذاری شود.
- بخش ورود اطلاعات: پشتیبانی از رها کردن فایل (drag & drop)، نمایش خطای خواندن فایل و چیدمان تازه.
- پنل: کارت «آخرین ماه ثبت‌شده» با درصد تغییر نسبت به ماه قبل، نوار نرخ پس‌انداز در نمای ماهانه، نوسازی کارت‌های آماری.
- جدول تراکنش‌ها: سربرگ چسبان، حالت خالی با دکمه پاک کردن فیلترها، شمارنده «نمایش X تا Y از Z» و صفحه‌بندی ایمن.
- هدر: هم‌ترازی با عرض محتوا، برچسب فیلترها، دکمه «پاک کردن فیلترها» و نمایش تعداد رکورد در بازه.
- یکدست‌سازی رنگ‌ها در حالت تیره (نشان‌های وضعیت دیگر رنگ ثابت روشن ندارند) و افزودن پرش به محتوا برای دسترس‌پذیری.
